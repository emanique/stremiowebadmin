# Stremio WebAdmin v0.1.5-rc.1 — Hash-scoped cache cleanup

## Status
Release candidate for controlled clean-install QA. Not a production-stable declaration.

## Changes
- Single verified-infohash purge removes every indexed media alias, partfiles, fastresume,
  subtitle SRT/metadata, labels, resume-name index, wanted selectors and pins.
- Both My Library removal and the WebAdmin cache removal use the shared purge operation.
- LRU eviction invokes hash cleanup only for verified hashes; unrelated titles remain untouched.
- A disappearing temporary file no longer fails the cache scanner during atomic renames.
- Protected files, symlinks and unrelated hashes cannot be targets of the purge.

## Acceptance
- 57 focused regression tests passed in an isolated container.
- Full-suite verification and real fresh-host deployment require separate completion.
- Never perform a destructive reinstall on a host holding non-disposable downloads.
- The source/DEB distributions do not embed translation model binaries, credentials,
  user cache, provider playlists, SSL private keys or VPN configuration.

## Clean-host installation
On an empty Debian/Ubuntu machine with supported Docker, Compose v2 and systemd:

```bash
sudo apt-get update && sudo apt-get install -y git
sudo git clone --branch v0.1.5-rc.1 --depth 1 \
  https://github.com/emanique/stremiowebadmin.git /opt/stremio-server-webadmin
sudo sh /opt/stremio-server-webadmin/packaging/stremio-webadmin-setup.sh
```

Use the bundled `scripts/provision-subtitle-models.sh` to install the baseline offline
models separately; other source-to-English language models must be provisioned separately.

## Limitations
Removing an item from the Stremio client's own Continue Watching or local app library
is not controlled by the server cache lifecycle. Existing sessions may remain in
telemetry briefly after content deletion. No automatic cleanup across unrelated hashes.
