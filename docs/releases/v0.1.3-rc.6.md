# Stremio Standalone v0.1.3-rc.6 — independent Gateway LAN address

**QA pre-release, not stable.** Supersedes v0.1.3-rc.5.

## Correction

The Stremio reconciler used to reject a valid MediaHub observer record when
the system's Internet default router was not the VPN Gateway appliance.
For example, the host could route through 192.168.1.1 while the Gateway's
management address was 192.168.1.231.

Stremio now independently validates the default route's **egress NIC, MAC and
source IP**, and accepts the explicitly configured private
`GATEWAY_IP` in `/etc/stremio-webadmin/port-sync.conf`. The observed
`gateway` field must match this pinned address, the policy ID and physical
host MAC. The observer alone authenticates to the Gateway's separate
read-only HTTPS API; Stremio owns .env, container recreation and rollback.

The public Gateway bootstrap has a matching source correction in the Gateway
public repository (commit `0605ba903f4ddfa0bdc9236dae3ce32a7226933c`).
The bootstrap assets are obtained on HTTPS TCP 443 with an explicitly
configured `MEDIAHUB_PORT_SYNC_GATEWAY_IP` and verified CA. The separate
authenticated status service runs on TCP 9443 **only when provisioned**.
