# Stremio WebAdmin Standalone v0.1.3-rc.1 — QA pre-release

**Pre-release only. Not approved for untrusted Internet exposure or production use.**

This candidate supersedes v0.1.2, which pointed at an older public commit
before the default WebAdmin authentication and Debian 13 package dependency fixes.

## Versions and topology

- Standalone distribution: **0.1.3-rc.1**
- WebAdmin platform: **3.0.14**, unchanged
- Stremio Core: **1.6.34**, unchanged
- Runtime: standalone Docker Compose, host-owned TCP/UDP BitTorrent port, HTTPS WebAdmin
- External VPN Gateway: optional authenticated port observer; no bundled Gluetun/Pi-hole stack
- Public repository: `emanique/stremiowebadmin`
- Development source: `emanique/StremioServerWebAdmin`
- Public CI: **no GitHub Actions**

## Changes since v0.1.2

1. Nginx WebAdmin HTTPS now requires Basic authentication on new installations. A
   random administrator password is generated once and shown during setup.
   The direct WebAdmin remains bound to loopback; a dedicated local script
   rotates its password.
2. Application update source defaults to the **public** standalone repository.
   Private DEV installations can override `STREMIO_SOURCE_REPO` in their `.env`.
3. Debian release package accepts `docker-compose` (native Debian 13) in
   addition to the other Docker Compose v2 package names.
4. Release promotion excludes DEV-only scripts and GitHub Actions. The public
   README remains identical to the private source README.
5. Python regression is validated using a real disk-backed temporary directory,
   preserving the production cache/free-space safety rules.

## Open acceptance criteria for stable release

- A complete first-run installation on a **separate QA host** with working
  systemd and Docker, including both containers healthy and HTTPS login.
- Real TV/WebPlayer IPTV, audio and subtitle extraction validation; FFmpeg
  subtitle failures observed with incomplete torrent data remain unresolved.
- Authenticated VPN Gateway lease change, BT listening port update and rollback
  following a simulated recreation failure.
- Release screenshots uploaded to both private DEV and public `docs/screenshots`.
- Administrative network access and Docker-socket privilege review.

A passing package installation is not equivalent to passing full runtime installation.
Do not expose this standalone admin service directly to the Internet.
