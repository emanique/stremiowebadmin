# Stremio WebAdmin v0.1.5-rc.4 — Offline Czech BPE support

## Scope
- Extend the existing local CTranslate2 subtitle translator with BPE/Moses
  support, keeping SentencePiece for all existing translations.
- Pinned Argos Czech→English model (BPE), SHA-256:
  `f1683b1ac5e826c7e3db2b0ea5d73191cdd695d6523b112363d8a769203dcb62`
  from the official Argos package distribution.
- Czech→English→Portuguese (pt-PT configured target).
- Recognise embedded Czech subtitle language tags and Czech sidecar SRT/VTT.
- Five models are provisioned on a new host: en_pt, fr_en, es_pt, ru_en, cs_en.
- Models remain outside the repository and are verified before installation.

## Acceptance and constraints
- Test real Czech phrases on an isolated Core image and test regression suites.
- No reset of existing cache or application profiles; install only via controlled
  upgrade after testing.
- Capturing another third-party Stremio addon's subtitles is not guaranteed.
  If the subtitle is only offered in the Stremio client, configure a supported
  source-addon manifest for server-side discovery. Download must not be broken.
- Prefix the source listing with supported languages only. No auto-translation
  of a different addon's choice without an explicit translated selection.
