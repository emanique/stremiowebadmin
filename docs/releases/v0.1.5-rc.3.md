# Stremio WebAdmin v0.1.5-rc.3 — clean snapshot bootstrap

## Purpose
Reproducible rebuild from a clean Ubuntu/Debian host following a user-managed
snapshot rollback. No credentials, torrents, SSL private keys, provider playlists,
VPN tokens, generated certificates or model binaries are published in Git.

## Changes over v0.1.5-rc.2
- Setup automatically provisions and verifies **en_pt, fr_en, es_pt, ru_en**
  with fixed SHA-256 before starting the Core (fail closed on mismatch).
- Verified Russian package: `translate-ru_en-1_9.argosmodel` with SHA-256
  `e9ba8bf722d10a4a4c39f74289d5938fd47eac08dbe4ed0afd22d89445a5c3ac`.
- The model root follows the literal `STREMIOSRV_SUBTITLE_MODELS_DIR` in `.env`,
  resolving relative paths beneath the installation root.
- Bootstrap ensures curl is available, in addition to Docker, Compose, Nginx.
- `STREMIO_PROVISION_SUBTITLE_MODELS=0` permits deliberate offline installation,
  but the WebAdmin will display zero models until they are provisioned.
- All v0.1.5-rc.2 hash-based delete fixes remain included.

## Clean install from public repository

```bash
sudo apt-get update && sudo apt-get install -y git
sudo git clone --branch main --depth 1 \
  https://github.com/emanique/stremiowebadmin.git \
  /opt/stremio-server-webadmin
sudo sh /opt/stremio-server-webadmin/packaging/stremio-webadmin-setup.sh
```

The source branch is not an immutable tag: verify `RELEASE_VERSION` reports
`0.1.5-rc.3` and record `git rev-parse HEAD` before installing.

## Acceptance criteria
1. Containers report healthy; Nginx HTTPS UI and Core/WebPlayer endpoints respond.
2. Four model pairs are installed and the WebAdmin lists EN/FR/ES/RU.
3. Russian-to-PT uses ru_en + en_pt and translates a sample caption.
4. One source hash deletion removes media aliases, partfile, fastresume, subtitle
   cache, labels, pin/wanted state, while another hash remains intact.
5. Reboot recovers Docker/HTTPS, and the Stremio App and WebPlayer both play
   compatible video with expected subtitles. IPTV integration requires a
   locally supplied source after the rollback.

## Limitations
No actual snapshot rollback is performed by this release process. VPN Gateway
registration/BT dynamic port lease, real IPTV credentials and external app
connectivity must be configured after the clean install. This is a QA candidate.
