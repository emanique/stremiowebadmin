# Stremio WebAdmin Standalone v0.1.2 — first public release candidate

> **Status: source published; tagged final release withheld until clean-install acceptance.**

## Product and source provenance

- **Standalone distribution version:** `0.1.2`
- **WebAdmin/platform version:** `3.0.14`
- **Integrated Stremio Core:** `1.6.34`
- **Private development authority:** `emanique/StremioServerWebAdmin`
- **Public clone:** `emanique/stremiowebadmin`
- **Public source promotion:** commit `f7cefbf` followed by documented QA/README updates
- **Reference platform:** `emmanique/stremio-webadmin`; a reference for documentation and upstream provenance, not the standalone runtime topology

This edition uses host networking, its own Docker Compose services and an independent HTTPS WebAdmin. It does **not** package the reference Gluetun/Pi-hole stack.

## Included features

- Stremio/libtorrent backend and WebPlayer endpoints
- Separate WebAdmin control plane, status, logs and configurable runtime parameters
- Direct Stream and HLS conversion, including supported live MPEG-TS IPTV remultiplexing
- Resume/Continue Watching integration and bounded FFmpeg/HLS lifecycle
- VAAPI detection and CPU fallback with host GPU reconciliation
- My Library and cache/stream management
- Host-owned TCP/UDP BitTorrent listening port and netcheck status
- Optional authenticated external VPN Gateway port observer, with Stremio responsible for `.env` and container recreation
- Debian source-build package, source TAR.GZ and SHA-256 manifests

## Installation contract

Public users may clone and install from the exact approved `main` revision:

```bash
sudo git clone https://github.com/emanique/stremiowebadmin.git /opt/stremio-server-webadmin
sudo sh /opt/stremio-server-webadmin/packaging/stremio-webadmin-setup.sh
```

The setup requires Docker Engine/Compose, Nginx, systemd, systemd-resolved (`resolvectl`), OpenSSL and networking tools already installed. It builds Docker images locally. These commands have **not yet passed a fresh-machine end-to-end acceptance test**. Do not expose WebAdmin TCP 443 outside a trusted administrator LAN.

When the release gate passes, publish the `.deb`, source TAR.GZ, and `SHA256SUMS` as release assets. Do not include `.env`, provider credentials, tokens, private keys, local Docker volumes, or CI artefacts.
