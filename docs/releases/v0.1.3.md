# Stremio Standalone v0.1.3 — versão estável

## Âmbito de aceitação

- Instalação limpa ou actualização controlada por tag exacta. Backend e WebAdmin saudáveis após reboot.
- WebAdmin HTTPS local sem autenticação Basic em LAN privada identificada (CIDR /24 ou mais restrito); restrição allow/deny activa. NUNCA publicar este WebAdmin sem um controlo de acesso WAN adequado.
- Stremio Core v1.6.34, WebAdmin v3.0.14, WebPlayer e biblioteca acessíveis; suporte VAAPI preservado após recreate.
- Gateway Multi v1.0.8 autorizado fornece NAT-PMP TCP/UDP dinâmico; reconciliador aplica a porta no .env e recria somente o Core. Testados lease válido, renovação, perda de autorização, fallback para 6881 após tolerância e recuperação.
- Testes funcionais reportados: reprodução, áudio, legendas, transcoding e retoma, incluindo através do ProxyWAN (esta validação não equivale à garantia de compatibilidade de qualquer cliente externo).
- Artefactos: arquivo de código-fonte, pacote Debian de código-fonte (exige execução do setup), SHA256SUMS.

## Condições de segurança e limitações

- A detecção inicial do Gateway usa TOFU após verificação do SAN IP TLS e associação da política IP/MAC. Exige LAN de gestão fiável, com defesa contra ARP/MAC spoofing. Para redes partilhadas, preferir CA pré-aprovada e observador autenticado por token.
- Sem política do Gateway, a porta local passa a 6881; isto não altera o kill-switch VPN nem implica que essa porta seja publicamente encaminhada.
- A aplicação Stremio Windows/TV nativa pode não suportar a autenticação do ProxyWAN via navegador. O addon privado é uma integração distinta e experimental.
- É necessário efectuar novo teste após upgrades de imagem base/upstream e alterações ao transcoding, certificados ou política VPN.

## Upgrade da RC9 (instalação por git clone)

\`\`\`bash
cd /opt/stremio-server-webadmin
sudo git fetch origin --tags
sudo git checkout v0.1.3
sudo sh packaging/stremio-webadmin-setup.sh
\`\`\`

Antes de mudar tag, salvaguardar .env e alterações locais e utilizar git stash se a árvore estiver modificada. Não remover volumes Docker nem reinicializar configurações persistentes.
