# Stremio WebAdmin Standalone v0.1.3-rc.4 — source-clone prerequisite fix

**QA pre-release, not approved as stable.** Supersedes v0.1.3-rc.3 for clean-clone installations.

## Fixed: `Missing prerequisite: docker`

The previous source-clone setup assumed Docker was already installed and aborted
on a newly restored Debian 13 host. The new setup invokes a bundled, idempotent
host-dependency bootstrap **before** creating its .env or application state.

- On Debian/Ubuntu, checks for Docker Engine, Compose v2, Nginx, Python 3,
  OpenSSL, iproute2 and systemd.
- Installs only missing APT packages, preferring distro-specific Compose v2
  names (`docker-compose-v2`, `docker-compose-plugin`, `docker-compose`).
- Verifies the `docker compose` CLI after the installation and enables Docker.
- Declines automatic APT installation on unsupported distributions and supports
  `STREMIO_SKIP_DEP_INSTALL=1` for administrators who provision manually.
- Does not reset network settings, Docker volumes or an existing .env.
- Both `git clone` installation and source-based Debian package keep the same
  application setup and Gateway observer reconciliation contract.

## Clean-clone installation

```bash
sudo git clone --branch v0.1.3-rc.4 --depth 1 \
  https://github.com/emanique/stremiowebadmin.git \
  /opt/stremio-server-webadmin
sudo sh /opt/stremio-server-webadmin/packaging/stremio-webadmin-setup.sh
```

- Targeted setup, package and public-source checks: **8 passed**.
- Tests cover the source-clone call order, package dependencies, Debian/Ubuntu
  support, opt-out and readable README commands.
- An existing-host smoke check confirmed that the bootstrap performs no
  reinstallation when all dependencies are already present.
- The previous `rc.3` passed simulated Gateway observer/reconciler and rollback

  audio and subtitles, and media-gallery assets remain separate acceptance gates.

Do not interpret the dependency bootstrap as approval of live VPN integration or
multimedia playback.
