# Stremio WebAdmin v0.1.5-rc.5

- Read-only per-hash diagnostics for peers, downloaded bytes and actual Core rates.
- Dashboard: Details button beside each torrent, independent of the App's native
  Statistics overlay.
- Strict SHA-1 infohash validation; the endpoint excludes per-peer addresses,
  tracker data and credentials.
- No changes to libtorrent, Subtitle Translator SRT intro, models, or cache.
- For titles where OpenSubtitles v3 returns zero sources, no translated selection
  can be advertised until a valid source becomes available.
- Tests: diagnostics, subtitle configuration and WebAdmin lifecycle.
