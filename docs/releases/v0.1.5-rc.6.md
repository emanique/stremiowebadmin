# v0.1.5-rc.6 — AI subtitle QA consolidation

17 November 2026. Candidate release based on functional QA v26 on `.201`.

- On-demand AI to PT subtitles via local Whisper/OpenVINO, native Stremio
  app and WebPlayer, with common GPU scheduler and isolated player sessions.
- SRT chunk cache by infohash/file/audio; preservation and hash eviction.
- Native subtitle style inheritance and playback-clock/partial-torrent
  buffering synchronisation.
- Subtitle Translator offline models, including Czech BPE, and stream
  diagnostics carried forward from other development branches.
- Bounded OpenVINO retries shared per block and internal error diagnostics.

**Not included:** model binaries, credentials, torrent data and user caches.

**Known limitations:** detected languages without an installed translation
path (such as Russian) and silence/no-speech blocks may fail. Fresh-install
validation on an independent machine remains outstanding.
